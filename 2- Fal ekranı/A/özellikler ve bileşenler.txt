B. TEKNİK LİSTESİ (UI Bileşen Analizi)
LAYOUT ARCHITECTURE
├── Device Frame: iPhone 14 Pro simülasyonu (393x852px, border-radius: 55px)
├── Dynamic Island: Absolute positioned pill (120x35px, static)
├── Safe Area: 54px status bar, 70px bottom nav padding
└── Viewport: user-scalable=no, overflow-hidden ana konteyner
NAVIGATION SYSTEM
├── Vanilla Router: router.navigate() SPA mimarisi, screen-based routing
├── Bottom Tab Bar: 3-item navigation (Home, History, Shop)
├── Global Back Button: Context-aware floating button (absolute positioned)
└── Active States: Nav item highlight, icon scale transform
GLASSMORPHISM COMPONENTS
├── Base Panel: backdrop-filter: blur(20px), rgba(255,255,255,0.05) bg
├── Gradient Border: mask-composite: exclude ile border gradient efekti
├── Parchment Variant: Gold-tinted glass (rgba(201,162,39,0.12))
└── Strong Variant: 30px blur, higher opacity (0.08)
CARD COMPONENTS
├── Mystic Card: Hover translateY(-8px), gold glow shadow
├── Tarot Card: perspective 3D, flip animation (rotateY)
├── Angel Card: White glassmorphism, selected state border
└── Zodiac Item: Square aspect-ratio, hover scale(1.05)
ANIMATION SYSTEM
├── Float: translateY loop (6s ease-in-out infinite)
├── Pulse Glow: Box-shadow alternation (gold/cyan)
├── Scan Line: Absolute positioned laser sweep (2s ease-in-out)
├── Ripple: Scale transform on click (0.6s ease-out)
└── Smoke Rise: Opacity + translateY combination (3s ease-out)
INPUT COMPONENTS
├── File Upload: Hidden input, custom drop zone styling
├── Drag Overlay: Visual feedback (border-color change)
├── Text Input: Custom textarea, placeholder styling
└── Category Badge: Pill-shaped buttons, color-coded states
FEEDBACK MECHANISMS
├── Toast System: Absolute positioned, slide-up animation
├── Modal Overlay: Backdrop blur, centered content, click-outside close
├── Progress Ring: SVG circle, stroke-dashoffset manipulation
└── Loading Orb: Conic gradient spinner (1s linear infinite)
SCROLL BEHAVIORS
├── Horizontal Deck: overflow-x: scroll, scroll-snap-type: x proximity
├── Momentum Scroll: -webkit-overflow-scrolling: touch
└── Scroll Hide: ::-webkit-scrollbar { display: none }
STATE INDICATORS
├── Token Badge: Coin icon + monospace amount display
├── Aspect Bars: Percentage-based width, gradient fills
├── DOT Indicators: 2-state circles (border vs filled gold)
└── Daily Quote: Static content with ornamental divider
TYPOGRAPHY SYSTEM
├── Display: 'Cinzel Decorative' (serif, decorative headers)
├── UI: 'Space Grotesk' (sans-serif, buttons, labels)
├── Body: 'Cormorant Garamond' (serif, readings, italic)
└── System: 'Inter' (fallback, inputs)
