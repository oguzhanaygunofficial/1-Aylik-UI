B. TEKNİK LİSTESİ (UI Bileşen Analizi)
LAYOUT ARCHITECTURE
├── Device Frame: iPhone 14 Pro (393x852px, 55px radius)
├── Aurora Background: CSS gradient animation (400% size, 15s loop)

├── Dynamic Island: Static pill (120x35px, blur backdrop)
└── Safe Area: 54px top, 70px bottom nav padding
NAVIGATION SYSTEM
├── Vanilla Router: navigateTo() screen switching
├── Soft Back Button: Circular glass button (absolute positioned)
├── Screen Reset: Entry/exit state cleanup functions
└── Scroll Management: el.scrollTop = 0 on navigation
GLASSMORPHISM SYSTEM
├── Organic Glass: backdrop-filter: blur(20px), rgba(255,255,255,0.08)
├── Gradient Overlays: 135deg multi-stop gradients (before pseudo)
├── Border Treatment: 1px solid rgba(255,255,255,0.15)
└── Inner Glow: Radial gradient highlights (fal-card-big::after)
INTERACTIVE CANVAS ELEMENTS
├── Water Bowl: 2D context, particle-based ripple system
├── Crystal Sphere: 2D context, trail particle animation
├── Hit Detection: Circle-based boundary checking
└── Animation Loop: requestAnimationFrame based rendering
CARD COMPONENTS
├── Fal Card Big: Gradient backgrounds, icon containers, price tags
├── Fal Bubble: Compact grid items, radial glow effects
├── Tarot Card: CSS transform rotation, drag states
└── Angel Card: Selection states, inner reveal pattern
ANIMATION SYSTEM
├── Breathe: Scale + opacity oscillation (6s ease-in-out)
├── Float Soft: TranslateY + rotate combination (8s)
├── Morph: Border-radius shape shifting (8s, organic blob)
├── Aurora: Background-position shift (15s, 400% size)
└── Ripple: Scale expansion with opacity decay (3s)
FORM ELEMENTS
├── Text Inputs: Custom styled with focus states
├── Textareas: Auto-resize disabled, fixed min-height
├── Chip Buttons: Toggle selection, group management
└── File Upload: Hidden input, visual proxy triggers
FEEDBACK MECHANISMS
├── Soft Toast: Blurred pill, slide-up animation (2.5s duration)
├── Visual Checkmarks: Upload confirmation indicators
├── Border Highlights: Active state color changes
└── Particle Effects: Canvas-based interactive feedback
TYPOGRAPHY SYSTEM
├── Serif: 'Cormorant Garamond' (headers, quotes, italic body)
├── Soft: 'Quicksand' (UI labels, buttons, small text)
├── System: 'Inter' (fallback, inputs)
└── Tracking: Wide letter-spacing on labels (2-4px)
STATE MANAGEMENT
