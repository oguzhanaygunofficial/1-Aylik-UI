A. ÖZELLİK LİSTESİ (İşlevsel Analiz)
================================================================================

01. ADIM TAKİP SİSTEMİ
    ├── Gerçek zamanlı adım sayacı (8,432+ simülasyonlu)
    ├── Günlük hedef belirleme (10K default)
    ├── İlerleme halkası (SVG circular progress)
    └── Linear progress bar gösterimi

02. KAZANIM & ÖDÜL SİSTEMİ
    ├── Çift para birimi (AdımCoin + NEX Token)
    ├── 2X/3X Boost mekanizması (süre bazlı çarpanlar)
    ├── Günlük/haftalık görev ödülleri
    └── Premium üyelik entegrasyonu

03. İSTATİSTİK & ANALİTİK
    ├── Haftalık bar chart (7 günlük performans)
    ├── KM/KCAL/DK metrik dönüşümü
    ├── Trend göstergesi (↑ +23%)
    └── Başarım (Achievement) tracking

04. SOSYAL & REKABET
    ├── Haftalık liderlik tablosu (Podium + Sıralama)
    ├── Seviye sistemi (LVL 12 + EXP bar)
    ├── Rozet/Badge koleksiyonu
    └── Arkadaş karşılaştırması

05. MARKETPLACE
    ├── Güçlendirici satın alma (Boostlar)
    ├── Premium abonelik tier'ı
    ├── Token dönüştürme modalı
    └── Oto-adım (background tracking) ürünü

06. KULLANICI YÖNETİMİ
    ├── Profil özelleştirme (Avatar ring)
    ├── Bildirim tercihleri (Toggle switches)
    ├── Sağlık entegrasyonu (HealthKit tarzı)
    └── Arka plan çalışma ayarları

================================================================================

B. TEKNİK LİSTESİ (UI Bileşen Analizi)
================================================================================

01. LAYOUT & NAVIGATION
    ├── Fixed left sidebar (70px offset)
    ├── Floating indicator line (active state)
    ├── Screen-based routing (4 views)
    └── Dynamic Island simulation (clock + dot)

02. DATA VISUALIZATION
    ├── SVG Circular Progress Ring (stroke-dasharray)
    ├── CSS Bar Charts (flexbox-based)
    ├── Linear Progress Bars (gradient fills)
    └── Podium visualization (flex align-items:flex-end)

03. INTERACTIVE ELEMENTS
    ├── Glassmorphism Cards (backdrop-filter:blur)
    ├── Toggle Switches (CSS-only state change)
    ├── Modal System (fixed overlay + scale animation)
    └── Hover states (transform:scale + glow)

04. TYPOGRAPHY SYSTEM
    ├── Syne (Display/Headings - 800 weight)
    ├── Syne Mono (Numbers/Data - monospace)
    └── Epilogue (Body/UI - 400-700 range)

05. FEEDBACK COMPONENTS
    ├── Toast-style boost notifications
    ├── Achievement unlock previews
    ├── Currency update animations
    └── Loading/progress states
